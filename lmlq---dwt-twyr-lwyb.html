    10. الملاحق - أدوات تطوير الويب

    نوضح هنا أين يمكن العثور على الأدوات المجانية التي تسمح بتطوير الويب باستخدام Java و PHP و ASP و asp.net وكيفية تثبيتها. وقد تطورت إصدارات بعض الأدوات، وقد لا تكون التفسيرات الواردة هنا مناسبة للإصدارات الأحدث. وسيتعين على القارئ التكيف مع ذلك... :

    • متصفح حديث قادر على عرض XML. تم اختبار أمثلة الدورة التدريبية باستخدام Internet Explorer 6.
    • إصدار حديث من JDK (مجموعة أدوات تطوير Java). يتضمن الإصدار JDK المكون الإضافي Java 1.4 للمتصفحات، مما يتيح لهذه الأخيرة عرض تطبيقات Java الصغيرة التي تستخدم الإصدار JDK 1.4.
    • بيئة تطوير Java لكتابة برامج Java الصغيرة. هنا هو JBuilder 7.
    • خوادم الويب: Apache، PWS (خادم الويب الشخصي، Cassini)، Tomcat.
      • يمكن استخدام Apache لتطوير تطبيقات الويب بلغة PERL (Practical Extracting and Reporting Language) أو PHP (Personal Home Page)
      • يمكن استخدام PWS لتطوير تطبيقات الويب بلغة ASP (Active Server Pages) أو PHP على منصات Windows. ويتيح Cassini التطوير بلغة ASP.NET.
      • يُستخدم Tomcat لتطوير تطبيقات الويب باستخدام برامج Java servlets أو صفحات JSP (Java Server pages)
    • نظام إدارة قواعد البيانات: MySQL
    • EasyPHP: أداة تجمع بين خادم الويب Apache ولغة PHP و SGBD MySQL

    php

    يجب أن يتيح لك زر معلومات php التحقق من حسن سير عمل ثنائي Apache-PHP: يجب أن تظهر صفحة معلومات PHP:

    تُظهر الشاشة أعلاه، على سبيل المثال، أن الوظائف اللازمة لاستخدام قاعدة البيانات MySQL موجودة بالفعل.

    في صفحة إدارة EasyPHP أيضًا، يتيح الرابط "الأسماء المستعارة" تعريف أسماء مستعارة مرتبطة بدليل ما. وهذا يسمح بوضع صفحات الويب في مكان آخر غير دليل www في شجرة easyPhp.

    إذا أدخلنا المعلومات التالية في الصفحة أعلاه:

    واستخدمنا الزر valider، فسيتم إضافة الأسطر التالية إلى الملف <easyphp>\apache\conf\httpd.conf:

    <Directory "e:/data/serge/web">
        Options FollowSymLinks Indexes
        AllowOverride None
        Order deny,allow
        allow from 127.0.0.1
        deny from all

    10.4. PHP

    لقد رأينا كيفية الحصول على PHP من خلال تطبيق EasyPhp. للحصول على PHP مباشرةً، سننتقل إلى الموقع http://www.php.net. لا يمكن استخدام PHP إلا في إطار الويب. يمكن استخدامه كلغة برمجة نصية في نظام Windows. قم بإنشاء البرنامج النصي التالي واحفظه باسم date.php:

    <?
   // نص برمجي php يعرض الوقت
  $maintenant=date("j/m/y, H:i:s",time());
  echo "Nous sommes le $maintenant";
?>

    في نافذة DOS، انتقل إلى دليل [date.php] وقم بتشغيله:

    dos>"e:\program files\easyphp\php\php.exe" date.php

    10.6. Vbscript، Javascript، Perlscript

    هذه اللغات هي لغات برمجة نصية لنظام ويندوز. يمكنها العمل في حاويات مختلفة مثل

    • Windows Scripting Host للاستخدام المباشر في نظام Windows، لا سيما لكتابة نصوص برمجية لإدارة نظام
    • Internet Explorer. ويتم استخدامها في صفحات HTML حيث تضفي عليها تفاعلية معينة لا يمكن تحقيقها باستخدام لغة HTML وحدها.
    • Internet Information Server (IIS) خادم الويب الخاص بـ Microsoft على NT/2000 ونظيره Personal Web Server (PWS) على Win9x. في هذه الحالة، يتم استخدام vbscript للبرمجة من جانب خادم الويب، وهي تقنية تسمى ASP (Active Server Pages) من قبل Microsoft.

    يمكن الحصول على ملف التثبيت من URL: http://msdn.microsoft.com/scripting واتباع روابط Windows Script. يتم تثبيت:

    • حاوية Windows Scripting Host، وهي حاوية تسمح باستخدام لغات برمجة متنوعة، مثل Vbscript و Javascript، بالإضافة إلى لغات أخرى مثل PerlScript التي تأتي مع Active Perl.
    • مترجم VBscript
    • مترجم Javascript

    دعونا نقدم بعض الاختبارات السريعة. لنقم بإنشاء البرنامج vbscript التالي:

    10.11. Jbuilder

    Jbuilder هو بيئة لتطوير تطبيقات Java. لإنشاء سيرفلتات Java التي لا تحتوي على واجهات رسومية، ليس من الضروري وجود مثل هذه البيئة. يكفي استخدام محرر نصوص و JDK. لكن JBuilder يوفر بعض المزايا الإضافية مقارنة بالطريقة السابقة:

    • سهولة التصحيح: يشير المُجمِّع إلى الأسطر الخاطئة في البرنامج ويسهل تحديد موقعها
    • اقتراح الكود: عند استخدام كائن Java، يعرض JBuilder قائمة بخصائصه وأساليبه مباشرةً. وهذا أمر عملي للغاية، خاصةً عندما نعلم أن معظم كائنات Java تحتوي على عدد كبير جدًا من الخصائص والأساليب التي يصعب تذكرها.

    يمكن العثور على JBuilder على الموقع http://www.borland.com/jbuilder. يجب ملء نموذج للحصول على البرنامج. يتم إرسال مفتاح التنشيط عبر البريد الإلكتروني. لتثبيت JBuilder 7، تم اتباع الخطوات التالية على سبيل المثال:

    • تم الحصول على ثلاثة ملفات مضغوطة: للتطبيق، وللوثائق، وللأمثلة. كل ملف من هذه الملفات المضغوطة له رابط منفصل على موقع JBuilder.
    • تم تثبيت التطبيق أولاً، ثم الوثائق، وأخيراً الأمثلة
    • عند تشغيل التطبيق لأول مرة، يُطلب إدخال مفتاح تفعيل: وهو المفتاح الذي تم إرساله إليك عبر البريد الإلكتروني. في الإصدار 7، يمثل هذا المفتاح في الواقع ملف نصي كامل يمكن وضعه، على سبيل المثال، في مجلد تثبيت JB7. عندما يُطلب المفتاح، قم بتحديد الملف المعني. وبمجرد القيام بذلك، لن يُطلب المفتاح مرة أخرى.

    هناك بعض الإعدادات المفيدة التي يجب إجراؤها إذا كنت ترغب في استخدام JBuilder لإنشاء سيرفلتات Java. في الواقع، الإصدار المسمى Jbuilder الشخصي هو إصدار مخفف لا يأتي مع جميع الفئات اللازمة لتطوير الويب بلغة Java. يمكننا جعل JBuilder يستخدم مكتبات الفئات التي يوفرها Tomcat. ونقوم بذلك على النحو التالي:

    عند التشغيل الأولي، يطلب [WebMatrix] خصائص projet.C الجديد، وهي إعداداته الافتراضية. يمكن تهيئته بحيث لا يظهر مربع الحوار هذا عند التشغيل. يمكن الحصول عليه من خلال الخيار [File/New File]. يتيح [WebMatrix] إنشاء هياكل أساسية لمختلف تطبيقات الويب. أعلاه، حددنا في (1) أننا نريد إنشاء تطبيق [ASP.ET Page] وهو عبارة عن صفحة ويب. في (2)، نحدد المجلد الذي سيتم وضع صفحة الويب هذه فيه. في (3) نحدد اسم الصفحة. يجب أن يكون لها اللاحقة .aspx. وأخيرًا في (4)، نحدد أننا نريد العمل بلغة VB.NET، حيث تدعم [WebMatrix] أيضًا لغتي C# وJ#.

    وبعد ذلك، يعرض [WebMatrix] صفحة لتحرير الملف [demo1.aspx]. نضع فيها الكود التالي:

    • تسمح علامة التبويب [Design] بـ"رسم" صفحة الويب التي نريد إنشاءها. ويتم ذلك كما هو الحال مع IDE لإنشاء تطبيقات Windows.
    • سيؤدي التصميم الجرافيكي لصفحة الويب في [Design] إلى إنشاء كود HTML في علامة التبويب [HTML]
    • قد تحتوي صفحة الويب على عناصر تحكم تولد أحداثًا يجب الاستجابة لها، مثل زر على سبيل المثال. سيتم إدارة هذه الأحداث بواسطة كود VB.NET الذي سيتم وضعه في علامة التبويب [Code]
    • في النهاية، الملف demo1.aspx هو ملف نصي يجمع بين كود HTML وكود VB.NET، وهو نتيجة التصميم الجرافيكي الذي تم في [Design]، والرمز HTML الذي تمت إضافته يدويًا في [HTML] والرمز VB.NET الموجود في [Code]. الملف بأكمله متاح في علامة التبويب [All].
    • يمكن لمطور ASP.ET ذي الخبرة إنشاء الملف demo1.aspx مباشرةً باستخدام محرر نصوص دون الحاجة إلى أي IDE.

<html>

    </form>

    تقبل تطبيق [WebServer]، المعروف أيضًا باسم خادم الويب Cassini، ثلاثة معلمات:

    • /port: رقم منفذ خدمة الويب. يمكن أن يكون أي رقم. القيمة الافتراضية هي 80
    • /path: المسار الفعلي لمجلد على القرص
    • /vpath: المجلد الافتراضي المرتبط بالمجلد الفعلي السابق. يجب الانتباه إلى أن الصيغة ليست /path=المسار بل /vpath:المسار، على عكس ما يذكره لوحة المساعدة أعلاه.

    لقد أظهرنا، في هذه الحالة بالذات، أن تطوير الويب ASP.NET يمكن أن يتم باستخدام محرر نصوص بسيط لكتابة صفحات الويب وخادم الويب Cassini لاختبارها. وهذا صحيح بغض النظر عن مدى تعقيد التطبيق. يوفر IDE [WebMatrix] بعض التسهيلات في التطوير، ولكنها قليلة. أداة مثل Visual Studio.NET أكثر كفاءة بكثير، ولكنها منتج تجاري.
